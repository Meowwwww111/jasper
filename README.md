# Jasper Ng — AI Software Engineer Portfolio

Open `index.html` for the portfolio. Open `weather-video-previews.html` to play the sunny, cloudy, and rainy Woodlands background loops.

The three backgrounds are 8-second H.264 MP4 loops. The main page selects one using current weather for Woodlands, Singapore and refreshes every 15 minutes. The optional “Use my location” button asks for location only when clicked. Serve the folder from HTTPS or localhost for weather lookups and location access; browsers may restrict those features on `file://` pages.
